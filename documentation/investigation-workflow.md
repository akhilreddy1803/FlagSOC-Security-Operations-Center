# FlagSOC Investigation Workflow

## Purpose

This document describes the workflow followed by a SOC analyst when investigating alerts generated by FlagSOC.

## Alert Investigation Process

Alert Generated
        ↓
Identify Alert Source
        ↓
Review Event Details
        ↓
Validate Host, User, IP and Process Information
        ↓
Correlate Related Events
        ↓
Determine Severity and Impact
        ↓
Document Investigation
        ↓
Close or Escalate

## Initial Triage

The analyst reviews:

- Alert rule ID
- Event ID
- Affected endpoint
- Username
- Timestamp
- Source IP
- Process information

## Investigation

Related events are reviewed to understand whether the activity is expected administrative activity or requires further investigation.

## Documentation

Investigation records include:

- Alert description
- Evidence collected
- Analysis performed
- Final decision

## SOC Outcomes

Alerts may be:

- Closed as expected activity
- Considered for detection tuning
- Escalated for further investigation
