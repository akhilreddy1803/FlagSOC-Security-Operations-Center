# FlagSOC Configuration Documentation

This directory contains documentation and sanitized sample configuration information related to the FlagSOC SOC lab.

## Purpose

The configuration documentation helps explain the main components used in the lab, including Wazuh, Sysmon, WireGuard, DNS, and endpoint monitoring.

## Security Notice

Private keys, passwords, API keys, certificates containing private material, authentication credentials, and other sensitive production configuration data are not included in this repository.

Only sanitized configuration examples should be added to `sample-configs/`.

## Main Components

- Wazuh Manager
- Wazuh Agent
- Sysmon
- WireGuard VPN
- BIND9 DNS
- Flask DDNS
- Nginx Reverse Proxy
